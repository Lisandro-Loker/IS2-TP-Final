# Installation

## Stable release

To install IS2 TP Final, run this command in your terminal:

```sh
uv add IS2-TP-Final
```

Or if you prefer to use `pip`:

```sh
pip install IS2-TP-Final
```

## From source

The source files for IS2 TP Final can be downloaded from the [Github repo](https://github.com/Lisandro-Loker/IS2-TP-Final).

You can either clone the public repository:

```sh
git clone https://github.com/Lisandro-Loker/IS2-TP-Final
```

Or download the [tarball](https://github.com/Lisandro-Loker/IS2-TP-Final/tarball/main):

```sh
curl -OJL https://github.com/Lisandro-Loker/IS2-TP-Final/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd IS2-TP-Final
uv sync
```
